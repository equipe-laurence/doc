Guide d'intégration API SMS¶

Ce guide documente l'API SMS actuelle basée sur Twilio avec authentification Entra ID (Azure AD).

Portée¶

  • Envoi d'un lot SMS d'urgence aux destinataires éligibles d'un bureau
  • Consultation de l'historique de diffusion
  • Réception des SMS entrants relayés par Twilio via Event Grid
  • Réception des statuts de livraison via Twilio

Authentification Entra ID¶

Tous les endpoints SMS (sauf Event Grid) nécessitent une authentification par jeton Bearer JWT émis par votre locataire Entra ID.

Flux d'authentification¶

  1. Inscrire l'application dans Entra ID (Tenant ID, Client ID, secret)
  2. Créer un groupe Entra ID pour les utilisateurs autorisés (SMS_Senders, etc.)
  3. Obtenir un token via MSAL, Azure CLI, ou flow client credentials
  4. Ajouter le header Bearer à chaque requête
  5. Le système valide le token et l'appartenance au groupe

Obtenir un token Entra ID¶

Via Azure CLI (développement local) :

az account get-access-token --resource api://votre-client-id --query accessToken -o tsv

Via MSAL (client credentials, pour service-to-service) :

curl -X POST "https://login.microsoftonline.com/<tenant-id>/oauth2/v2.0/token" \
  -d "client_id=<client-id>" \
  -d "client_secret=<client-secret>" \
  -d "scope=api://votre-client-id/.default" \
  -d "grant_type=client_credentials"

Via MSAL (desktop app, pour utilisateurs interactifs) :

Utilisez la librairie MSAL.NET ou MSAL.js pour obtenir un token interactif.

Matrice des endpoints¶

Méthode Route Authentification Description
GET /api/notifications/sms/form Bearer Entra ID + groupe SMS Retourne le formulaire HTML de sélection
POST /api/notifications/sms/send-by-bureau Bearer Entra ID + groupe SMS Envoie un SMS d'urgence aux destinataires éligibles
POST /api/sms/inbound Event Grid (validation) Reçoit les SMS entrants relayés par Twilio
POST /api/sms/delivery-status Event Grid (validation) Reçoit les statuts de livraison Twilio

1) GET /api/notifications/sms/form¶

Retourne un formulaire HTML pour sélectionner un bureau et composer un message.

Headers requis¶

Authorization: Bearer <token-entra-id>

Réponse 200¶

HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

<!DOCTYPE html>
<html>
  <head>
    <title>SMS Notification Form</title>
  </head>
  <body>
    <h1>Envoyer un SMS aux employés</h1>
    <form method="POST" action="/api/notifications/sms/send-by-bureau">
      <label for="bureau">Bureau:</label>
      <select name="bureau" id="bureau" required>
        <option value="MTL">Montréal</option>
        <option value="TOR">Toronto</option>
      </select>
      <label for="message">Message:</label>
      <textarea name="message" id="message" required></textarea>
      <button type="submit">Envoyer</button>
    </form>
  </body>
</html>

Erreurs possibles¶

  • 401 Unauthorized — Token manquant ou invalide
  • 403 Forbidden — Utilisateur authentifié mais pas membre du groupe SMS autorisé

2) POST /api/notifications/sms/send-by-bureau¶

Envoie un SMS à tous les destinataires éligibles d'un locationCode. Les destinataires sont résolus depuis BaseTi (base d'employés locaux) stockée dans Azure Table Storage.

Headers requis¶

Authorization: Bearer <token-entra-id>
Content-Type: application/x-www-form-urlencoded
Idempotency-Key: <cle-unique-uuid> (recommandé; généré si absent)

Requête (form-encoded)¶

locationCode=MTL&messageBody=Alerte+securite+evacuation

Réponse 200¶

{
  "locationCode": "MTL",
  "totalEmployees": 5,
  "sent": 4,
  "failed": 1,
  "auditId": "audit-2026-05-22-14-32-15-uuid",
  "details": [
    {
      "employeeNumber": "000123",
      "name": "Jean Tremblay",
      "phone": "+1514***7890",
      "status": "sent",
      "messageId": "twilio-msg-123",
      "timestamp": "2026-05-22T18:32:15Z"
    },
    {
      "employeeNumber": "000124",
      "name": "Marie Côté",
      "phone": "+1514***1234",
      "status": "failed",
      "error": "InvalidPhoneNumber",
      "timestamp": "2026-05-22T18:32:15Z"
    }
  ]
}

Erreurs possibles¶

  • 400 Bad Request — Paramètres manquants ou invalides
  • 401 Unauthorized — Token manquant ou expiré
  • 403 Forbidden — Utilisateur pas membre du groupe SMS autorisé
  • 404 Not Found — Bureau inexistant ou aucun employé trouvé
  • 500 Internal Server Error — Erreur Twilio ou base de données

3) POST /api/sms/inbound¶

Endpoint Event Grid pour recevoir les SMS entrants relayés par Twilio.

Headers¶

Event Grid ajoute automatiquement les en-têtes de validation.

Payload attendu¶

[
  {
    "eventType": "Microsoft.Communication.IncomingSMSReceived",
    "data": {
      "from": "+15145557890",
      "message": "STOP"
    }
  }
]

Mots-clés traités¶

  • STOP, STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT, ARRET → Ajout au registre opt-out
  • START, UNSTOP, YES → Retrait du registre opt-out

Le système répond aussi aux événements Microsoft.EventGrid.SubscriptionValidationEvent pour la validation initiale de la souscription.

4) POST /api/sms/delivery-status¶

Endpoint Event Grid pour recevoir les statuts de livraison SMS de Twilio.

Payload attendu¶

[
  {
    "eventType": "Microsoft.Communication.SMSDeliveryReportReceived",
    "data": {
      "to": "+15145557890",
      "messageId": "twilio-msg-123",
      "deliveryStatus": "Delivered",
      "tag": "broadcast-audit-uuid"
    }
  }
]

Stockage¶

  • Table : SmsDeliveryStatus
  • Clé : PartitionKey = premiers 8 caractères du MessageId, RowKey = MessageId
  • Le numéro To est masqué avant persistance
  • tag est utilisé comme corrélation avec la diffusion (audit ID)

Idempotence¶

  • Le header Idempotency-Key est recommandé pour POST /api/notifications/sms/send-by-bureau
  • Une réponse est mise en cache dans la table SmsIdempotency pendant 24h
  • En cas de retry avec la même clé, la réponse mise en cache est rejouée sans renvoyer le lot

Codes d'erreur HTTP¶

Code Description
200 Succès — au moins un SMS envoyé
400 Requête malformée (paramètres manquants ou invalides)
401 Token Entra ID manquant, expiré ou invalide
403 Utilisateur authentifié mais pas autorisé (pas membre du groupe SMS)
404 Bureau inexistant ou aucun destinataire trouvé
500 Erreur serveur (Twilio, base de données, etc.)

Limites connues¶

  • Les endpoints d'historique ne supportent pas encore la pagination/filtrage via query params
  • Les événements entrants et de livraison dépendent d'une souscription Event Grid correctement configurée sur Twilio
  • Voir le fichier SmsGroupRequirement.cs pour les détails sur la gestion des groupes Entra ID (limitation connue : groupes >200 membres)
