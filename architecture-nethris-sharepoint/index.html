Architecture d'intégration Nethris → SharePoint + SMS d'urgence¶

Vue d'ensemble¶

Ce document décrit l'architecture de l'application Azure Function qui :

  1. Synchronise les rapports Nethris — récupère les rapports automatisés du système RH Nethris et les téléverse dans une bibliothèque de documents SharePoint privée chaque nuit. Un registre de synchronisation (Azure Table Storage) empêche les doublons.
  2. Envoie des SMS d'urgence — diffuse des messages textes via Azure Communication Services aux employés d'un emplacement donné, avec gestion des opt-out, idempotence, et piste d'audit.

Diagramme des composantes Azure¶

Séquence du cycle de synchronisation¶

1. Fonction déclenchée (timer ou HTTP GET)
2. L'orchestrateur appelle INethrisAuthClient.LoginAsync() → identifiant de session
3. L'orchestrateur appelle INethrisReportClient.GetAvailableReportsAsync(sessionId)
4. Pour chaque rapport (trié par date d'exécution) — isolation d'erreur par rapport :
   a. ISyncLedger.TryClaimAsync(reportProdId) → passer si false (déjà réclamé)
   b. INethrisReportClient.DownloadReportAsync(sessionId, reportProdId) → contenu du rapport
   c. ISharePointClient.UploadFileAsync(rootFolder, baseFileName, bytes, contentType) → copie racine
   d. ISharePointClient.UploadFileAsync(archiveFolder, archiveFileName, bytes, contentType) → copie archive
   e. ISyncLedger.RecordSyncAsync(reportProdId, archivePath, syncedAtUtc, reportExecDate)
   f. (Optionnel) Si rapport source SMS : ingestion de l'index des destinataires
5. (Optionnel) Si IBaseTiIngestionService configuré : ingestion du classeur BaseTI
6. L'orchestrateur appelle LogoutSafelyAsync(sessionId, CancellationToken.None) dans le bloc finally
7. Retourne SyncCycleResult avec les résultats par rapport

Responsabilités par couche¶

Core (EquipeLaurence.Core)¶

Tout ce qui ne communique pas avec le monde extérieur.

  • Clients/ — Contrats pour les dépendances externes INethrisAuthClient, INethrisReportClient, ISharePointClient, ISyncLedger, ISmsClient, IRecipientIndexClient, IOptOutRegistryClient, ISmsAuditClient, ISmsIdempotencyStore
  • Models/ — DTO — pas de logique, pas de dépendances NethrisReportSummary, NethrisReportContent, NethrisApiModels, SyncResult, SmsSendResult, RecipientRecord, SharePointFileInfo
  • Configuration/ — POCO d'options (pattern Options) NethrisOptions, SharePointOptions, LedgerOptions, AcsOptions, AadAuthOptions
  • Services/ — Orchestrateur — logique métier pure INethrisReportSyncService, NethrisReportSyncService

Contrats d'interfaces¶

Interfaces du pipeline Nethris → SharePoint¶

public interface INethrisAuthClient
{
    Task<string> LoginAsync(CancellationToken cancellationToken = default);
    Task LogoutAsync(string sessionId, CancellationToken cancellationToken = default);
}

public interface INethrisReportClient
{
    Task<IReadOnlyList<NethrisReportSummary>> GetAvailableReportsAsync(
        string sessionId, CancellationToken cancellationToken = default);
    Task<NethrisReportContent> DownloadReportAsync(
        string sessionId, string reportProdId, CancellationToken cancellationToken = default);
}

public interface ISharePointClient
{
    Task<string> UploadFileAsync(
        string folderPath, string fileName, byte[] content, string contentType,
        CancellationToken cancellationToken = default);

    Task ValidateAccessAsync(CancellationToken cancellationToken = default);

    Task<IReadOnlyList<SharePointFileInfo>> ListFilesAsync(
        string folderPath, CancellationToken cancellationToken = default);
}

public interface ISyncLedger
{
    Task<bool> HasBeenSyncedAsync(string reportProdId, CancellationToken cancellationToken = default);

    /// Réclame atomiquement un rapport pour la sync.
    /// Retourne true si la réclamation a été acquise, false si déjà réclamé.
    Task<bool> TryClaimAsync(string reportProdId, CancellationToken cancellationToken = default);

    Task RecordSyncAsync(string reportProdId, string sharePointPath,
        DateTimeOffset syncedAtUtc, DateTimeOffset reportExecDate,
        CancellationToken cancellationToken = default);
}

Gestion des secrets¶

  • Azure Key Vault stocke tous les identifiants Nethris, Azure Communication Services et les identifiants client Azure AD.
  • Le Function App référence Key Vault via une identité managée (aucun mot de passe dans la configuration).
  • Azure App Configuration centralise les paramètres non-secrets avec des références Key Vault intégrées.
  • Les pipelines d'infrastructure déploient avec provisionSecretValues=false par défaut afin que les valeurs existantes des secrets Key Vault ne soient pas écrasées lors des exécutions de routine.
  • L'approvisionnement initial des secrets est une action manuelle explicite (workflow_dispatch avec provision-secrets=true) qui lit les valeurs à partir des secrets d'environnement GitHub plutôt que des fichiers de paramètres versionnés.

Stratégie de gestion des erreurs¶

Isolation par rapport¶

Chaque rapport se synchronise indépendamment. Une erreur sur un rapport n'interrompt pas le cycle — les autres rapports continuent d'être traités. Le SyncCycleResult rapporte tous les résultats, y compris les échecs.

Garantie de session Nethris¶

Le bloc finally de l'orchestrateur garantit que LogoutAsync est toujours appelé, même en cas d'exception. Cela empêche les fuites de session avec l'API Nethris.

Politique de réessai¶

Composant Stratégie
HTTP Nethris Polly exponentiel (3×, 2s/4s/8s)
SharePoint Polly exponentiel (3×, 429/503)
Registre sync Pas de réessai
Function Réessai auto du runtime

Journalisation et observabilité¶

  • Journalisation structurée via ILogger<T> partout.
  • Intégration Application Insights pour la télémétrie, les traces et les alertes.
  • Chaque cycle de sync journalise : heure de début, nombre de rapports, résultat par rapport, heure de fin.
  • Les échecs incluent les détails de l'exception pour le diagnostic.

Alertes¶

  • Configurer des alertes Application Insights pour :
  • Tout cycle de sync avec HasFailures == true
  • Échec complet du cycle de sync (exception non gérée)
  • Aucune activité de sync depuis 48 heures (vérification de la planification)

Considérations de sécurité¶

Flux d'authentification¶

Système Authentification
Nethris API Login custom (HTTPS/TLS 1.2)
SharePoint (Graph) ClientSecretCredential / DefaultAzureCredential
Table Storage Identité managée
Key Vault Identité managée
/sms/send Jeton AAD (Identity.Web)
/sms/inbound Event Grid + ACS

Sécurité réseau¶

  • L'API Nethris requiert TLS 1.2 avec des suites de chiffrement spécifiques.
  • Tous les appels sortants passent exclusivement par HTTPS.
  • Le Function App peut optionnellement utiliser l'intégration VNet pour contrôler le trafic sortant.
  • Aucune exposition réseau entrante au-delà du runtime Functions.

Principe du moindre privilège¶

  • Utilisateur de service Nethris : accès en lecture seule (getList, getFile uniquement).
  • Inscription d'application SharePoint : permission Sites.Selected limitée au site cible uniquement.
  • Table Storage : rôle Table Contributor sur la table spécifique uniquement.

Inscription DI (FunctionAppStartup.ConfigureServices)¶

// --- Azure App Configuration ---
// Ajouté via ConfigureAppConfiguration() :
// configuration.AddAzureAppConfiguration(options => {
//     options.Connect(endpointUri, new DefaultAzureCredential())
//         .ConfigureKeyVault(kv => kv.SetCredential(credential));
// });

// --- Options avec validation au démarrage ---
services.AddOptions<NethrisOptions>()
    .BindConfiguration(NethrisOptions.SectionName)        // "Nethris"
    .ValidateDataAnnotations().ValidateOnStart();

services.AddOptions<SharePointOptions>()
    .BindConfiguration(SharePointOptions.SectionName)     // "SharePoint"
    .ValidateDataAnnotations().ValidateOnStart();

services.AddOptions<LedgerOptions>()
    .BindConfiguration(LedgerOptions.SectionName)         // "Ledger"
    .ValidateDataAnnotations().ValidateOnStart();

// --- Clients Nethris (HttpClient typé + Polly) ---
services.AddHttpClient<INethrisAuthClient, NethrisAuthClient>()
    .AddPolicyHandler(GetRetryPolicy());
services.AddHttpClient<INethrisReportClient, NethrisReportClient>()
    .AddPolicyHandler(GetRetryPolicy());

// --- GraphServiceClient (singleton) ---
services.AddSingleton<GraphServiceClient>(sp => {
    // Utilise ClientSecretCredential si AzureAd:TenantId/ClientId/ClientSecret sont présents,
    // sinon DefaultAzureCredential.
    return new GraphServiceClient(credential, ["https://graph.microsoft.com/.default"]);
});

// --- SharePoint (Scoped) ---
services.AddScoped<ISharePointClient, SharePointClient>();

// --- Registre de sync (Scoped avec factory) ---
services.AddSingleton<TableServiceClient>(sp => {
    // Créé via LedgerTableServiceClientFactory à partir de AzureWebJobsStorage + LedgerOptions
});
services.AddScoped<ISyncLedger>(sp => {
    var serviceClient = sp.GetRequiredService<TableServiceClient>();
    var ledgerOptions = sp.GetRequiredService<IOptions<LedgerOptions>>().Value;
    var tableClient = serviceClient.GetTableClient(ledgerOptions.TableName);
    return new TableStorageSyncLedger(tableClient, logger);
});

// --- Orchestrateur ---
services.AddScoped<INethrisReportSyncService, NethrisReportSyncService>();

// --- SMS / Azure Communication Services (conditionnel) ---
if (smsEnabled)  // Sms:Enabled ou auto-détection via présence des clés Azure Communication Services
{
    services.AddOptions<AcsOptions>()
        .BindConfiguration(AcsOptions.SectionName)     // "Acs"
        .ValidateDataAnnotations().ValidateOnStart();

    services.AddSingleton<ISmsClient, AcsSmsClient>();
    services.AddAuthentication()
        .AddMicrosoftIdentityWebApi(configuration, AadAuthOptions.SectionName);  // "AzureAd"
}
else
{
    services.AddSingleton<ISmsClient, DisabledSmsClient>();
}

// --- Clients SMS Table Storage (toujours enregistrés) ---
services.AddScoped<IRecipientIndexClient, TableStorageRecipientIndexClient>();
services.AddScoped<ISmsIdempotencyStore, TableStorageSmsIdempotencyStore>();
services.AddScoped<ISmsAuditClient, TableStorageSmsAuditClient>();
services.AddScoped<IOptOutRegistryClient, TableStorageOptOutRegistryClient>();

Structure de dossiers SharePoint¶

Les fichiers sont déposés directement à la racine du RootFolder configuré (/FSources/Nethris en production). Il n'y a pas de sous-dossiers par année, mois ou jour.

Bibliothèque de documents SharePoint
└── FSources/
    └── Nethris/
        ├── Emp2_20260501_010140.xlsx
        └── Nom00_20260501_010140.xlsx

Format du nom de fichier : {NomRapport}_{yyyyMMdd_HHmmss}.{ext}

Le nom est construit dans NethrisReportSyncService.BuildFileName() : les caractères spéciaux sont remplacés par _, le nom est tronqué à 200 caractères, et l'horodatage provient de ExecutionDateUtc du rapport Nethris.

Pipeline SMS d'urgence¶

Le pipeline SMS permet de diffuser un message d'urgence à tous les employés éligibles d'un emplacement donné.

Flux d'envoi (POST /api/sms/send)¶

  1. Validation du jeton porteur Azure AD (Microsoft.Identity.Web).
  2. Extraction de l'en-tête Idempotency-Key — rejet si absent.
  3. Vérification de l'idempotence (ISmsIdempotencyStore) — rejeu de la réponse en cache si déjà traité.
  4. Lecture des destinataires pour l'emplacement (ISmsRecipientSource.GetByLocationAsync), résolus depuis la table BaseTi.
  5. Filtrage des opt-out (IOptOutRegistryClient.IsOptedOutAsync).
  6. Envoi individuel via ISmsClient.SendSmsAsync pour chaque destinataire éligible.
  7. Enregistrement de la piste d'audit (ISmsAuditClient.RecordBroadcastAsync) — le corps du message est stocké uniquement sous forme de hash SHA-256.
  8. Mise en cache de la réponse pour l'idempotence.

Webhook entrant (POST /api/sms/inbound)¶

  1. Validation Event Grid de l'abonnement si nécessaire.
  2. Extraction du mot-clé (STOP/ARRET/START/UNSTOP…).
  3. Mise à jour du registre opt-out/opt-in (IOptOutRegistryClient).
  4. Retour d'une réponse de validation Event Grid ou 204 No Content.

Activation conditionnelle¶

Le SMS est activé si Sms:Enabled = true OU si les deux clés ACS (ConnectionString, PhoneNumber) sont présentes dans la configuration. Quand désactivé, DisabledSmsClient est injecté (stub inerte qui retourne un échec).
