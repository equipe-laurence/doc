Guide d'acquisition d'un numéro de téléphone — Twilio¶

Ce guide couvre l'acquisition complète d'un numéro de téléphone pour l'envoi de SMS via Twilio depuis le Canada, en choisissant le type de numéro le mieux adapté à votre cas d'usage.

Audience : Administrateurs Azure, responsables RH, responsable vie privée
Durée totale : 1–6 semaines (selon le type de numéro et le scénario réglementaire)

Vue d'ensemble¶

L'acquisition d'un numéro SMS dans Twilio suit ces étapes clés :

  1. Prérequis — Créer le compte Twilio et préparer le dossier documentaire
  2. Type de numéro — Choisir entre local (local long code) et sans-frais (toll-free)
  3. Acquisition via la console — Obtenir le numéro en quelques minutes
  4. Vérification / enregistrement — Soumettre le formulaire de conformité selon le type choisi
  5. Conformité réglementaire — Respecter CASL, Loi 25, CRTC
  6. Configuration technique — Intégrer le numéro avec Key Vault et webhooks
  7. Plan d'action — Étapes de déploiement et d'approbation

Pour le contexte réglementaire complet, consultez Conformité SMS.

Étape 1 — Prérequis¶

✅ Compte Twilio¶

  • Compte Twilio actif — Les comptes d'essai (trial) peuvent envoyer des SMS uniquement aux numéros vérifiés. Utilisez un compte payant pour un usage en production. Créer un compte : https://www.twilio.com/try-twilio
  • Accès console — Vous disposez des droits Owner ou Administrator sur le compte Twilio.
  • Facturation activée — Ajoutez un mode de paiement valide sous Account → Billing.
  • Accès Azure Key Vault — Rôle Key Vault Secrets Officer (ou supérieur) sur le coffre de l'environnement cible pour stocker les credentials.

Vérifier vos credentials Twilio : 

# Récupérer l'Account SID depuis la console :
# https://console.twilio.com/ → Dashboard → Account SID

# Tester avec curl
curl -X GET "https://api.twilio.com/2010-04-01/Accounts/<ACCOUNT_SID>.json" \
  -u "<ACCOUNT_SID>:<AUTH_TOKEN>"
# Doit retourner un objet JSON avec "status": "active"

📋 Documents à préparer (checklist)¶

Avant de commencer, rassemblez ces documents. Ils seront requis lors de la vérification toll-free ou de l'enregistrement de la marque (A2P) selon le type de numéro choisi.

  • Raison sociale complète — Nom officiel de votre organisation (ex. : Équipe Laurence Inc.)
  • Adresse commerciale officielle — Adresse physique complète (rue, ville, province, code postal) — en Canada
  • Coordonnées du responsable — Nom complet, titre, adresse courriel professionnelle, numéro de téléphone
  • Description du cas d'usage — Résumé de votre utilisation (ex. : Notifications d'urgence et de sécurité aux employés)
  • Volume estimé mensuel — Nombre approximatif de SMS par mois (ex. : 100–500 ou 2 000)
  • 2–3 exemples de messages types — Snippets de messages réels que vous enverrez (accents français acceptés)
  • Preuve du mécanisme d'opt-out — Capture d'écran ou document montrant comment les utilisateurs se désinscrire (STOP/ARRET)
  • Clause de consentement — Copie du libellé utilisé dans votre contrat d'emploi ou manuel des employés mentionnant les SMS

Étape 2 — Type de numéro¶

❓ Options disponibles au Canada via Twilio¶

Contrairement à Azure Communication Services (ACS), Twilio supporte plusieurs types de numéros SMS au Canada :

Type SMS via Twilio Délai Recommandation
Local long code (10 chiffres, ex. : 514-XXX-XXXX) ✅ Oui 1–3 jours ✅ Recommandé — apparence locale, moins coûteux
Toll-Free (1-8XX-XXX-XXXX) ✅ Oui 1–15 jours ✅ Compatible — similaire à ACS
Short Code (5–6 chiffres) ✅ Oui (via CWTA) 8–12 semaines ⚠️ Déconseillé pour un démarrage rapide
Alphanumeric Sender ID ❌ Non au Canada — ❌ Non disponible

Avantage clé de Twilio vs ACS : Les numéros locaux 10 chiffres au Canada supportent le SMS via Twilio, contrairement à ACS qui ne prend en charge que les numéros sans-frais.

🎯 Quel type choisir?¶

Critère Local long code Toll-Free
Apparence pour le destinataire Numéro local (ex. : 514) 1-800 / 1-888
Coût mensuel (USD) ~$1.15 ~$2.00
Coût SMS sortant (USD) ~$0.0079/message ~$0.0079/message
Processus de vérification Enregistrement de marque (A2P) Formulaire Toll-Free Verification
Délai avant premier SMS 1–5 jours 1–15 jours
Gestion STOP automatique ✅ Oui ✅ Oui

Recommandation pour Équipe Laurence

Un numéro local avec indicatif régional québécois (514, 438, 418, etc.) est recommandé : il est reconnaissable par les employés, moins coûteux, et Twilio gère automatiquement les STOP/ARRET.

💰 Tarification (USD)¶

Élément Local long code Toll-Free
Numéro (location) ~$1.15/mois ~$2.00/mois
SMS sortant (Canada) ~$0.0079 par message* ~$0.0079 par message*
SMS entrant ~$0.0079 par message ~$0.0079 par message

*Un message Twilio = 160 caractères (GSM-7). Les accents français peuvent activer UCS-2 et réduire à 70 caractères par segment.

Tarifs en USD

La facturation Twilio est en dollars américains (USD). Prévoyez ~1.35–1.40 pour la conversion USD→CAD.

Exemple de coûts mensuels (local long code) :

  • 1 numéro local + 500 SMS = $1.15 + $3.95 = ~$5.10 USD/mois (~$7 CAD)
  • 1 numéro local + 5 000 SMS = $1.15 + $39.50 = ~$40.65 USD/mois (~$55 CAD)

Étape 3 — Acquisition du numéro dans la console Twilio¶

1. Naviguer vers Phone Numbers¶

  1. Connectez-vous à https://console.twilio.com/
  2. Dans le menu de gauche, sélectionnez Phone Numbers → Manage → Buy a number

2. Rechercher un numéro¶

Remplissez le formulaire de recherche :

Champ Valeur (local) Valeur (toll-free)
Country Canada 🍁 Canada 🍁
Number Type Local Toll Free
Capabilities ✅ SMS ✅ SMS
Area Code (local seulement) 514 (Montréal), 438, 418, etc. —

Cliquez sur Search pour afficher les numéros disponibles.

3. Sélectionner et acquérir¶

  1. Parcourez la liste et choisissez un numéro (ex. : +15145551234)
  2. Cliquez sur Buy à côté du numéro souhaité
  3. Une boîte de confirmation s'affiche avec le coût mensuel
  4. Confirmez l'achat — le numéro est immédiatement disponible dans votre compte

Acquisition instantanée

Le numéro est disponible dans votre compte Twilio immédiatement. Cependant, il peut ne pas être utilisable pour l'envoi de SMS à grande échelle avant la complétion de la vérification/enregistrement (Étape 4).

4. Vérifier l'acquisition¶

Allez à Phone Numbers → Manage → Active Numbers.

Local: +15145551234
  Capabilities: SMS ✅, Voice ✅
  Status: Active
  Monthly cost: $1.15 USD

Étape 4 — Vérification / Enregistrement (obligatoire)¶

Le processus de vérification diffère selon le type de numéro choisi.

Option A — Numéro local : Enregistrement de marque (A2P)¶

⚠️ REQUIS POUR L'ENVOI DE VOLUMES ÉLEVÉS

Pour éviter le filtrage des messages par les opérateurs, Twilio exige un enregistrement de marque et de campagne pour les numéros locaux destinés à l'envoi en volume.

4a. Créer un profil de confiance (Trust Hub)¶

  1. Dans la console Twilio, allez à Messaging → Regulatory Compliance → Trust Hub
  2. Cliquez sur + Create new profile
  3. Sélectionnez Business comme type de compte
  4. Remplissez les informations :
  5. Business name : Nom légal (ex. : Équipe Laurence Inc.)
  6. Business type : Sélectionnez (ex. : Corporation, Non-profit)
  7. Business address : Adresse physique complète au Canada
  8. Business registration number : Numéro de NEQ (Québec) ou numéro fédéral
  9. Primary contact : Coordonnées du responsable technique ou RH

4b. Enregistrer la marque (Brand Registration)¶

  1. Allez à Messaging → Senders → A2P Brands
  2. Cliquez sur + Register Brand
  3. Liez le profil de confiance créé à l'étape précédente
  4. Remplissez les informations supplémentaires sur votre organisation
Champ Valeur recommandée
Company Name Nom légal
Website URL Site web officiel de votre organisation
Vertical Human Resources ou Public Sector
Stock Symbol Laisser vide si non coté en bourse

4c. Enregistrer la campagne¶

  1. Allez à Messaging → Senders → A2P Campaigns
  2. Cliquez sur + Register Campaign
  3. Sélectionnez la marque enregistrée
  4. Remplissez les informations :
Section Champs Détails
Use Case Type de campagne Emergency ou Notifications/Alerts
Description Résumé du cas d'usage Notifications d'urgence et de sécurité aux employés actifs
Message Samples 2–5 exemples Messages réels que vous enverrez
Opt-In / Opt-Out Mécanisme Décrire le processus STOP/ARRET et comment l'opt-in est obtenu
Subscriber Opt-In Checkbox Confirmer que vous avez le consentement des destinataires
  1. Cliquez sur Submit Campaign

4d. Lier le numéro à la campagne¶

  1. Dans votre campagne approuvée, allez à la section Phone Numbers
  2. Cliquez sur + Add Phone Number
  3. Sélectionnez le numéro local acquis à l'Étape 3
  4. Cliquez sur Save

⏱️ Délais d'approbation (local long code)¶

Étape Délai
Vérification du profil de confiance 1–2 jours ouvrables
Approbation de la marque 1–3 jours ouvrables
Approbation de la campagne 1–5 jours ouvrables
Total optimal 3–10 jours ouvrables
Total complexe Jusqu'à 3 semaines

Option B — Numéro sans-frais : Toll-Free Verification¶

⚠️ OBLIGATOIRE POUR L'ENVOI DE SMS

Les opérateurs canadiens filtrent les SMS en provenance de numéros sans-frais non vérifiés. La vérification est obligatoire pour un envoi en production.

4e. Accéder au formulaire¶

  1. Dans la console Twilio, allez à Phone Numbers → Manage → Active Numbers
  2. Sélectionnez votre numéro sans-frais
  3. Sous l'onglet Messaging, cliquez sur Register for toll-free verification

4f. Remplir le formulaire¶

Section Champs Détails
Business Info Raison sociale Nom légal de votre organisation
Adresse commerciale Adresse physique complète (Canada)
Site web URL de votre organisation
Contact Person Nom complet Personne responsable
Titre/fonction Rôle (ex. : HR Manager, IT Director)
Courriel professionnel Adresse d'accès continu
Numéro de téléphone Numéro professionnel
Use Case Description Résumé de l'utilisation (ex. : Emergency notifications to employees)
Volume mensuel Nombre approximatif (ex. : 500 SMS/month)
Message Samples 2–5 exemples Messages réels
Consentement Confirmer que vous avez le consentement des destinataires
Opt-Out Mécanisme STOP Décrire la gestion des désinscriptions

⏱️ Délais d'approbation (toll-free)¶

Scénario Délai
Cas optimal 1–3 jours ouvrables
Cas standard 5–10 jours ouvrables
Cas complexe (information manquante) Jusqu'à 15 jours ouvrables
Rejet + resoumission +5–10 jours supplémentaires

Twilio vous informera par courriel une fois la vérification terminée.

Étape 5 — Conformité réglementaire¶

📜 CASL — Loi canadienne anti-pourriel¶

La Loi canadienne anti-pourriel (CASL) encadre tous les messages électroniques commerciaux au Canada, y compris les SMS.

✅ Bonne nouvelle : Exemption pour SMS d'urgence

Les SMS d'urgence et de sécurité aux employés sont exemptés du consentement préalable si :

  • L'employé est en relation d'emploi actuelle
  • Le SMS concerne un risque de sécurité ou une urgence
  • Le message n'est pas promotionnel

Checklist CASL :

  • Documenter la relation d'emploi — Conservez les registres d'embauche et les dossiers RH.
  • Implémenter le mécanisme STOP/ARRET — Twilio gère automatiquement les mots-clés STOP, STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT. Ajoutez ARRET (français) via un webhook entrant si nécessaire (voir Étape 6).
  • Conserver les registres d'opt-out — Synchronisez les désinscriptions Twilio avec votre table SmsOptOut (voir Conformité SMS — Désinscription).
  • Identification de l'expéditeur — Le SMS doit clairement identifier votre organisation (ex. : [Alerte Urgence - Équipe Laurence]).
  • Auditer les consentements — Conservez des preuves (contrats, manuels) que les employés consentent au SMS.

Twilio et la gestion automatique des STOP

Contrairement à ACS, Twilio supprime automatiquement les destinataires qui répondent STOP et renvoie une réponse de confirmation. Vous devez quand même synchroniser ces désinscriptions avec votre table SmsOptOut via le webhook entrant pour maintenir votre propre registre de conformité.

🛡️ Loi 25 (Québec) — EFVP obligatoire¶

La Loi 25 — Loi sur la protection des renseignements personnels du Québec est la loi de confidentialité la plus stricte au Canada.

⚠️ ACTION OBLIGATOIRE : EFVP avant déploiement

Vous devez compléter une Étude de faisabilité et d'impact sur la vie privée (EFVP) AVANT de déployer votre système SMS. L'EFVP documente les risques de confidentialité liés aux données qui transiteront par l'infrastructure Twilio (serveurs principalement aux États-Unis).

Responsabilités :

  • Mandater le responsable vie privée — Nommez une personne pour mener l'EFVP.
  • Documenter le flux de données — Décrivez comment les numéros de cellulaire et messages transitent via Twilio vers les serveurs américains de Twilio Inc. (San Francisco, CA).
  • Analyser les risques transfrontaliers — Les serveurs de Twilio sont aux É.-U.; documentez les garanties contractuelles (Twilio Data Processing Addendum, clauses contractuelles types UE-US) et limitations.
  • Rétention des données — Définissez une politique de rétention (minimum 2 ans pour les journaux d'audit conformément à la Loi 25). Les logs Twilio sont conservés 30 jours par défaut; exportez-les dans Azure Table Storage.
  • Obtenir l'approbation — L'EFVP doit être approuvée par la direction avant le déploiement en production.

Pour plus de détails, consultez la Politique de conformité Loi 25.

📞 CRTC — Autorités de régulation canadiennes¶

Le Conseil de la radiodiffusion et des télécommunications canadiennes (CRTC) régule les SMS au Canada.

Obligations CRTC :

  • Vérification / enregistrement — Complétée via l'Étape 4 (couvre les exigences CRTC).
  • STOP/ARRET keywords — Vous devez honorer les demandes d'opt-out immédiatement. Twilio gère STOP automatiquement; ajoutez ARRET via webhook.
  • No unsolicited SMS — Aucun SMS non sollicité (marketing, publicité) aux employés. Les notifications de sécurité sont autorisées.
  • Identity and routing — Le numéro affiché correspond à votre organisation (pas d'usurpation d'identité).

Étape 6 — Configuration technique post-acquisition¶

🔐 Secrets dans Key Vault¶

Une fois votre numéro approuvé, intégrez les credentials Twilio dans votre architecture sécurisée.

Où stocker les credentials :

  1. Dans votre Key Vault (ex. : eql-kv-prod), créez deux secrets :
Secret Description Source
twilio-account-sid Identifiant de compte Twilio console.twilio.com → Dashboard
twilio-auth-token Jeton d'authentification Twilio console.twilio.com → Dashboard 
az keyvault secret set \
  --vault-name eql-kv-prod \
  --name twilio-account-sid \
  --value "<ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx>"

az keyvault secret set \
  --vault-name eql-kv-prod \
  --name twilio-auth-token \
  --value "<votre-auth-token>"
  1. Dans App Configuration (ex. : eql-appconfig-prod), créez quatre clés :
Clé Valeur Type de contenu
Sms:Provider Twilio text/plain
Twilio:AccountSid Référence Key Vault application/vnd.microsoft.appconfig.keyvaultref+json;charset=utf-8
Twilio:AuthToken Référence Key Vault application/vnd.microsoft.appconfig.keyvaultref+json;charset=utf-8
Twilio:FromNumber +15145551234 text/plain 
APPCONFIG_NAME="eql-appconfig-prod"
KV_URL="https://eql-kv-prod.vault.azure.net"

az appconfig kv set --name $APPCONFIG_NAME --key "Sms:Provider" \
  --value "Twilio" --content-type "text/plain" --yes

az appconfig kv set --name $APPCONFIG_NAME --key "Twilio:AccountSid" \
  --value "{\"uri\":\"${KV_URL}/secrets/twilio-account-sid/\"}" \
  --content-type "application/vnd.microsoft.appconfig.keyvaultref+json;charset=utf-8" --yes

az appconfig kv set --name $APPCONFIG_NAME --key "Twilio:AuthToken" \
  --value "{\"uri\":\"${KV_URL}/secrets/twilio-auth-token/\"}" \
  --content-type "application/vnd.microsoft.appconfig.keyvaultref+json;charset=utf-8" --yes

az appconfig kv set --name $APPCONFIG_NAME --key "Twilio:FromNumber" \
  --value "+15145551234" --content-type "text/plain" --yes
  1. Référencez dans votre code C# : 
    var options = configuration.GetSection(TwilioOptions.SectionName).Get<TwilioOptions>();
var client = new TwilioRestClient(options.AccountSid, options.AuthToken);

Pour les étapes détaillées, consultez Guide de configuration du fournisseur SMS.

🪝 Webhook entrant pour opt-out (ARRET français)¶

Twilio gère automatiquement STOP (anglais), mais le mot-clé ARRET (français, requis par CASL) nécessite un webhook entrant :

  1. Configurer le webhook dans la console Twilio :
  2. Allez à Phone Numbers → Manage → Active Numbers → sélectionnez votre numéro
  3. Sous Messaging → A message comes in, configurez :
    • Type : Webhook
    • URL : https://{functionApp}.azurewebsites.net/api/sms/inbound/twilio
    • Méthode : POST

  4. Cliquez sur Save

  5. Écouter les mots-clés supplémentaires dans la Function Azure :

  6. ARRET (français), DESABONNER
  7. Mettre à jour la table SmsOptOut avec le numéro qui s'est désinscrit

  8. Retourner TwiML vide (200 text/xml) pour confirmer la réception

  9. Vérifier la signature Twilio (X-Twilio-Signature) pour sécuriser l'endpoint : 

    var validator = new RequestValidator(authToken);
bool isValid = validator.Validate(requestUrl, parameters, signature);

Pour la configuration complète, consultez Guide d'intégration API SMS — Gestion des STOP/ARRET.

Étape 7 — Plan d'action¶

Semaine 1 — Actions immédiates¶

Objectif : Créer le compte, acquérir le numéro et amorcer le processus réglementaire.

  • Créer le compte Twilio payant — Activer la facturation sur console.twilio.com
  • Mandater responsable vie privée — Nommez le responsable qui mènera l'EFVP
  • Préparer le dossier documentaire — Rassemblez tous les documents (section 1)
  • Acquérir le numéro — Complétez la recherche et l'achat dans la console (Étape 3 — 10 min)
  • Démarrer l'enregistrement — Créez le profil de confiance et soumettez la marque ou la vérification toll-free (Étape 4 — 30–60 min)
  • Informer la direction — Notification que le processus a commencé (EFVP + enregistrement en attente)

Durée: ~3 heures de travail

Semaines 2–3 — Conformité réglementaire¶

Objectif : Obtenir l'approbation réglementaire et finaliser la conformité.

  • Mener l'EFVP — Le responsable vie privée amorce l'Étude de faisabilité et d'impact
  • Documenter le consentement SMS — Ajoutez une clause dans le contrat d'emploi ou le manuel RH
  • Préparer le mécanisme opt-out — Concevoir le flux STOP (auto Twilio) + ARRET (webhook)
  • Approbation de l'enregistrement reçue? — Vérifiez votre courriel et la console Twilio
  • Revue CASL — Documenter pourquoi les SMS d'urgence sont exemptés du consentement préalable

Durée: 2–5 jours ouvrables (principalement en attente de l'approbation Twilio)

Semaines 3–4 — Développement technique¶

Objectif : Intégrer le numéro Twilio dans le système et mettre en place les mécanismes de conformité.

  • Secrets Key Vault — Créer twilio-account-sid et twilio-auth-token dans Key Vault
  • App Configuration — Configurer Sms:Provider = Twilio et les trois clés Twilio
  • Webhook entrant — Créer la Function pour capturer les ARRET (français)
  • Synchronisation opt-out — Synchroniser les désinscriptions Twilio avec la table SmsOptOut
  • Table SmsAuditLog — Implémenter l'audit (rétention 2 ans minimum; exporter depuis Twilio si nécessaire)
  • Validation de signature Twilio — Implémenter RequestValidator sur l'endpoint inbound
  • Tests unitaires — Vérifier la logique opt-out et la désinscription

Durée: ~10–15 heures de développement

Semaines 4–5 — Validation et déploiement¶

Objectif : Tester complètement le système et le déployer en production.

  • EFVP approuvée — Confirmation que l'Étude de faisabilité et d'impact est terminée et approuvée
  • Test end-to-end envoi — Envoyer un SMS test à un numéro de test autorisé
  • Test end-to-end opt-out — Répondre STOP au numéro; vérifier que Twilio bloque les suivants
  • Test bilingue — Envoyer ARRET (français); vérifier que le webhook met à jour SmsOptOut
  • Validation piste d'audit — Vérifier que SmsAuditLog enregistre chaque tentative avec TwilioSid
  • Revue sécurité — Audit final avant production (secrets en Key Vault, validation de signature)
  • Communication aux employés — Informer les employés que le SMS est désormais actif (procédure opt-out)
  • Déploiement production — Passer Sms:Provider de "Disabled" à "Twilio" dans App Configuration

Durée: 1–2 semaines (principalement attente d'approbations)

Semaines 6+ — Exploitation¶

Objectif : Surveiller et maintenir le système en production.

  • Surveillance des erreurs — Surveiller le taux d'échec des SMS dans Application Insights et la console Twilio (Messaging → Logs)

Questions fréquentes¶

Q: Puis-je utiliser un numéro local (long code) pour le SMS au Canada avec Twilio?¶

R: Oui. C'est un avantage majeur de Twilio vs Azure Communication Services : les numéros locaux 10 chiffres au Canada supportent l'envoi et la réception de SMS via Twilio. ACS ne permet que les numéros sans-frais pour les SMS au Canada.

Q: Combien de temps avant que mon numéro soit utilisable?¶

R:

  • Acquisition : immédiate (< 5 min)
  • Enregistrement A2P (local) : 3–10 jours ouvrables
  • Vérification toll-free : 1–15 jours ouvrables
  • Total : 3–15 jours de délai avant l'envoi en production

Les numéros locaux peuvent envoyer des SMS en faible volume dès l'acquisition, mais les volumes élevés nécessitent l'approbation de la campagne A2P.

Q: Twilio gère-t-il automatiquement les STOP comme ACS?¶

R: Oui, et c'est un avantage. Twilio gère automatiquement les mots-clés STOP, STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT et bloque automatiquement les envois vers les numéros désinscrit. Contrairement à ACS, vous n'avez pas à implémenter cette logique vous-même. Cependant, vous devez ajouter ARRET (français) via un webhook pour respecter les obligations CASL au Québec.

Q: Et si la vérification ou l'enregistrement est rejeté?¶

R: Twilio vous informera par courriel et via la console avec le motif du rejet. Corrigez les informations manquantes ou inexactes et resoumettez. Prévoyez +5–10 jours supplémentaires. Les motifs fréquents sont : cas d'usage vague, exemples de messages insuffisants, absence d'URL du site web.

Q: Dois-je compléter l'EFVP (Loi 25) avant ou après l'enregistrement Twilio?¶

R: L'enregistrement Twilio peut commencer immédiatement. L'EFVP doit être complétée AVANT la mise en production. Vous pouvez les paralléliser.

Q: Les employés ont-ils besoin d'un consentement écrit pour le SMS?¶

R: Pour les SMS d'urgence et de sécurité, la relation d'emploi suffit (exemption CASL). Cependant, le consentement documenté (via contrat, manuel) est recommandé pour des raisons d'audit et de conformité Loi 25.

Q: Quel est le coût exact comparé à ACS?¶

R: Twilio est légèrement moins cher pour les numéros locaux :

Twilio (local) ACS (toll-free)
Numéro/mois ~$1.15 USD ~$2.00 CAD
SMS sortant ~$0.0079 USD ~$0.0085 CAD
SMS entrant ~$0.0079 USD Non disponible

Note : les tarifs Twilio sont en USD et peuvent varier. Consultez twilio.com/pricing pour les tarifs actuels.

Q: Puis-je utiliser le même numéro pour la voix et le SMS?¶

R: Oui. Les numéros Twilio locaux et sans-frais supportent les deux canaux si vous configurez les capacités correspondantes lors de l'acquisition.

Support et dépannage¶

Erreurs courantes¶

Erreur Cause probable Solution
21408 - Permission to send an SMS has not been enabled Numéro non approuvé pour SMS Vérifier l'enregistrement A2P ou la vérification toll-free dans la console
21610 - Message cannot be sent to the 'To' number because the customer has replied with STOP Destinataire désinscrit Normal — ne pas renvoyer avant un opt-in explicite
20003 - Authenticate / 401 Credentials invalides Vérifier Account SID et Auth Token dans Key Vault
21211 - Invalid 'To' phone number Numéro destinataire malformé Normaliser en E.164 (ex. : +15145550100)
21606 - The 'From' number is not a valid SMS-capable inbound phone number FromNumber mal configuré Vérifier que Twilio:FromNumber correspond à un numéro actif dans votre compte
Campaign rejected: "Incomplete opt-in description" Description opt-in insuffisante Détailler comment et quand les employés consentent au SMS

Signification du statut d'enregistrement¶

Statut Signification Actions
Pending ⏳ En attente d'examen Attendre (1–10 jours)
Approved ✅ Approuvé — prêt pour l'envoi Associer le numéro à la campagne
Failed ❌ Rejeté — voir motif Corriger et resoumette
In Review 🔍 Examen en cours Attendre — ne pas resoumette

Prochaines étapes¶

Une fois votre numéro approuvé :

  1. Stockez les credentials dans Key Vault (twilio-account-sid, twilio-auth-token)
  2. Configurez App Configuration (Sms:Provider = Twilio, Twilio:FromNumber)
  3. Configurez le webhook entrant pour les opt-out ARRET (français)
  4. Déployez les tables SmsAuditLog et SmsOptOut dans Azure Storage
  5. Testez l'envoi et la réception avec un employé pilote
  6. Activez la fonction SMS en production
  7. Notifiez les employés de la nouvelle capacité SMS

Pour l'implémentation technique, consultez Guide d'intégration API SMS.
