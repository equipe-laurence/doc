ℹ️ À propos du projet¶

  • Stack : Azure Functions (.NET 10), SharePoint Online, SMS Twilio, Table Storage, Graph API ; POC AdSync (console .NET, Active Directory)
  • Sécurité : Secrets gérés via Key Vault, conformité Loi 25/CASL/TCPA
  • CI/CD : GitHub Actions, déploiement infra Bicep
  • Contact : Équipe sur GitHub
